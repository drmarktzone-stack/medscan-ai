# knowledge/criteria — מאגר קריטריונים קליניים מובנים

ידע מעוגן-מקור שמזין את מנוע-הקריטריונים (דרמטולוגיה/אלרגיה/ראומטולוגיה/זיהומולוגיה).

- **סטטוס:** כל פריט `draft_needs_verification` — טעון אימות רופא/ה מול המקור והפרוטוקול המקומי **לפני** שימוש קליני. אין להעלות `draft` לפלט מטופל.
- **אצווה 1** (`batch1_criteria_seed.json`): קוואסאקי, HSP, קדחת שגרון (Jones 2015), SLE (EULAR/ACR 2019), דרמטומיוזיטיס, SJS/TEN+SCORTEN, DRESS, אנפילקסיס (WAO 2020), דרמטיטיס אטופית, אורטיקריה+UAS7, patch-test (ICDRG), מלנומה+דרמוסקופיה. הספים המספריים אומתו מול המקורות.
- **ערוצי-קלט:** לכל קריטריון מסומן אם הוא נראה במצלמה, דורש בדיקה/מישוש של הרופא, או מעבדה/ביופסיה — כדי שהמנוע ישאל את הרופא על מה שאינו נראה.
- **עיקרון:** כל הבדיקה והניקוד דטרמיניסטיים בקוד; ה-LLM מתאר ומנסח בלבד.
