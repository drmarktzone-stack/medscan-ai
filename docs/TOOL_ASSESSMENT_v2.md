# MedScan — הערכת כלים מלאה + מפת שיפורים (v2)

> עדכון אחרי סבב הבנייה. הכל מוטמע, build נקי, checkpoints שמורים, לוגיקה מאומתת ב-node. כל פריט קליני `draft` עד אימות רופא.

## מסגרת
כלי תמיכה בהחלטות — לא מחליף רופא. יכול לעלות על זיכרון מומחה בודד בממדים מדידים: רוחב, עקביות, זמינות, הוגנות גווני-עור, מדידה כמותית לפי הספר, אחזור-השוואה.

## כלי-כלי (כן / לא / לשיפור)
- **ECG** — כן: 7-שלבים, dual-QTc, 19 קריטיים, שער-איכות, PDF, ולידציה, A2a. לא: A2b, אטלס. שיפור: A2b, היפוך-לידים אמיתי, אכלוס PTB-XL.
- **עור** — כן: דרמוסקופיה+אלרגיה מחוברים, מורפומטריה, ולידציית-הוגנות, מעקב-נגע. לא: חיבור מורפומטריה/מעקב לעמוד, אטלס. שיפור: אכלוס ISIC, סמן קנה-מידה, body-map.
- **רדיולוגיה** — כן: critical rule-out (12), מדידות Caffey (~19) + תצוגה. לא: עוד מדדים, אטלס, comparison. שיפור: מדיאסטינום/טובוסים/גיל-עצם, MIMIC-CXR.
- **מעבדה** — כן: ארכיטקטורה מצוינת. לא: ReferenceRange ריקה→לא-שמיש. שיפור(חסום): אכלוס טווחים, מחשבונים.
- **הקשר-מטופל / אבחנה-מבדלת** — כן: must-not-miss בקוד, כיסוי מוצהר. לא: תלוי KB. שיפור: לוח-חיסונים, הרחבת KB.
- **פרוטוקולים** — כן: מנוע בטוח. לא: Protocol ריקה. שיפור(חסום): בניית פרוטוקולים מאומתים.
- **ידע/הערכה** — כן: נלסון verbatim, ולידציה. לא: הכל draft, כיסוי חלקי. שיפור: דשבורד כיסוי, אימות באצוות, verified-only.
- **תשתיות** — כן: אנטי-הזיה עשירה, אחזור-אטלס. לא: אטלסים ריקים, אין flywheel.

## שיפורים חוצי-מערכת (לפי ערך)
